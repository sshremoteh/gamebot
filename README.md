# 🎰 Telegram Dice GameBot (Игровой бот на интерактивных эмодзи)

Полнофункциональный игровой Telegram-бот, работающий на **официальных анимированных эмодзи Telegram (Dice API)**: Баскетбол, Футбол, Боулинг, Дартс, Слоты/Рулетка и Кости.

Каждый бросок анимируется прямо в чате Telegram в реальном времени, а исход броска рассчитывается серверами Telegram.

---

## 🌟 Основные возможности

- 💰 **Стартовый баланс: 10 000 монет** при первом запуске (`/start`).
- 🎮 **6 интерактивных игр на эмодзи Telegram**:
  - 🏀 **Баскетбол**: чистый 3-очковый (swish) — **x3.0**, обычное попадание — **x1.5**, промах — ставка сгорает (**x0**).
  - ⚽ **Футбол**: пушка в «девятку» — **x3.0**, гол в угол — **x2.0**, гол по центру — **x1.5**, мимо/штанга — **x0**.
  - 🎳 **Боулинг**: СТРАЙК (все 10 кеглей) — **x3.5**, 9 кеглей — **x2.0**, 5-6 кеглей — **x1.4**, 3 кегли — **x0.8**, 0-1 кегля — **x0**.
  - 🎯 **Дартс**: точное яблочко (Bullseye в центр) — **x4.0**, красное кольцо — **x2.5**, внутренний сектор — **x1.8**, внешний — **x1.2**, мимо — **x0**.
  - 🎰 **Слоты 777 (Рулетка)**: Джекпот `777` — **x10.0**, Три лимона `🍋🍋🍋` — **x5.0**, Три винограда `🍇🍇🍇` — **x4.0**, Три BAR `🍫🍫🍫` — **x3.0**, Две семёрки `7️⃣7️⃣` — **x2.0**, Любая пара — **x1.4**.
  - 🎲 **Кости**:
  - **Классический бросок**: выпало 6 — **x3.0**, выпало 5 — **x2.0**, выпало 4 — **x1.5**, выпало 3 — **x1.0** (возврат), 1 или 2 — **x0**.
  - **Режим угадывания чисел (как в @spins)**:
    - 1 число (`кости 3`) — **x5.0** при точном попадании
    - 2 числа (`кости 3 5`) — **x3.0** при выпадении любого из двух
    - 3 числа / чет / нечет (`кости чет`, `кости нечет`, `кости 1 2 3`) — **x2.0**
- 💬 **Быстрая игра словами в чате (как в @spins)**:
  - `ставка 100` / `ставка 500 монет` / `ставка 1к` / `ставка вабанк` — мгновенно меняет вашу ставку.
  - `баскетбол` (или `баскет`, `🏀`) — сразу запускает бросок мяча с текущей ставкой!
  - `футбол` (или `футбик`, `⚽`), `боулинг` (`🎳`), `дартс` (`🎯`), `слоты` (`🎰`), `кости` (`🎲`).
  - Возможность указать ставку прямо в команде: например, `баскетбол 500`, `кости 3 5 1000`.
- ⏱ **Реалистичная задержка анимации**: бот ждет завершения полета мяча / вращения барабанов перед публикацией результата.
- 💵 **Гибкая система ставок**: быстрые кнопки (100, 250, 500, 1 000, 2 500, Ва-банк) + ввод любой произвольной суммы.
- 👤 **Профиль игрока**: детальная статистика (победы, поражения, винрейт %, максимальный выигрыш, чистый профит, история последних 5 игр).
- 🎁 **Ежедневный бонус**: случайная награда от 1 000 до 2 500 монет каждые 24 часа.
- 🆘 **Помощь банкроту («Второе дыхание»)**: если баланс опустился ниже 50 монет, можно получить 1 000 монет для продолжения игры.
- 🏆 **Таблица лидеров (Топ-10)** богатейших игроков по балансу монет.
- 🛡 **Защита от спама и гонок**: блокировка повторных кликов до завершения текущего броска.
- 🗄 **База данных**: асинхронный SQLite (`aiosqlite`).

## 🚀 Быстрый старт

### 1. Получение токена бота
1. Откройте Telegram и найдите официального бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Укажите имя и username для вашего бота.
4. Скопируйте полученный API токен (вид: `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`).

### 2. Настройка файла `.env`
Откройте файл [`.env`](file:///C:/Users/Camille/Desktop/agy/gamebot/.env) в корне проекта и вставьте ваш токен:
```ini
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
STARTING_BALANCE=10000
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск бота
```bash
python main.py
```

### 5. Запуск тестов
Для проверки всей игровой логики и базы данных выполните:
```bash
python test_bot.py
```

## 📁 Структура проекта

```
gamebot/
├── .env                # Переменные окружения (BOT_TOKEN, стартовый баланс)
├── .env.example        # Пример конфигурации
├── config.py           # Настройки приложения
├── main.py             # Точка входа, инициализация бота и регистрация роутеров
├── requirements.txt    # Зависимости (aiogram, aiosqlite, python-dotenv)
├── test_bot.py         # Набор автотестов для игровой механики и базы данных
└── bot/
    ├── __init__.py
    ├── database.py     # Асинхронный модуль работы с SQLite (балансы, история, статистика)
    ├── games.py        # Логика расчета результатов для каждого интерактивного эмодзи
    ├── keyboards.py    # Инлайн-клавиатуры (меню, выбор игр, ставки, повторы)

    └── handlers/       # Обработчики сообщений и кнопок
        ├── start.py        # /start, /help, главное меню
        ├── game.py         # Выбор игры, ставки, бросок эмодзи, начисление выигрыша
        ├── profile.py      # /profile, статистика и история игр
        ├── bonus.py        # /bonus (ежедневный), /bailout (помощь банкроту)
        ├── leaderboard.py  # /top (таблица лидеров)
        └── rules.py        # /rules (справочник правил и коэффициентов)
```
